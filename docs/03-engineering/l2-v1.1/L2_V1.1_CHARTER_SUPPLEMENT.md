## 1. 北极星与产品不变量

VRAE 是 VEYFRONT 面向中国出口制造业的**证据化采购商体验诊断和 Rebuild 获客引擎**，不是通用 SEO 分数器、工业设备工程选型器、自动销售或自动建站系统。

- L0 Scout、L1 Initial Audit、L2 Deep Audit、L3 Sales 四层保持不变。**L2 为专业分析深度，SourcePolicy 为具体数据/行动权限，两者正交。** 可以在离线合成、合法持有及允许的公开只读资料上完成 L2；非公开/受保护数据或需特别许可的交互操作须逐项授权。无资料记录 UNKNOWN，不阻断其余合法有据诊断。
- EvidencePack、RuleExecution、Finding、AIInterpretation、DeepReport、ReportVersion、ReviewDecision、RebuildBrief 不混用事实权威；模型、报告和任何 DTO 不能签发任务/审核/交付权限。
- 原始网页证据、出处/时间/哈希/定位、规则版本、政策与租户不可被建议或审核修改。事实、假设、推荐、UNKNOWN、ACCESS_BLOCKED 和 NOT_APPLICABLE 各有独立语义。
- 人工 Controlled 审核不是正式真人认证；内部 Brief 不是 VF 的真实咨询、正式报价、E2/E3 或 L2M 可执行的授权交付单。
- 真实客户资料/外部模型/公开分享/上线、自动广告或触达均不因本附件获准。

## 2. 四大架构补强

### 2.1 业务架构

五类任务：DISCOVER（找得到）、UNDERSTAND（懂技术与用途）、TRUST（能复核供应商声明）、INQUIRE（携产品上下文询价）、SEARCH_TECHNICAL（可发现与基础可用性）。**一项规则失败不直接等于一个可报价的网站缺陷。**

L2 报告必须将以下六类分开：
1. 已证实的网站可改善障碍（有对应适用规则及原始证据）。
2. 已观察的正常路径/正向事实（不能强凑问题）。
3. 情景标量矛盾或采购资料差距（不能自动认定工程适配失败/网站故障）。
4. 真实性或合规独立核验事项（证书、工厂、资质只记录声明）。
5. 买方/企业待补资料与未观察范围（UNKNOWN，不作为缺陷）。
6. 商业影响与 Rebuild 价值假设（需人工校准，不得虚构损失、排名、投递、E2/E3）。

L2 产物有两层表达：面向业务负责人的 Executive Summary（建议1–2页，不能删除完整事实范围）及可溯源的专业深度报告/蓝图。每项 Rebuild 建议包含影响的买家任务、原 Finding/Source 绑定、页面/资料动作、责任人、企业待补、前置依赖、复验方法、标准候选或需定制评估。实际服务与定价以经确认的 VEYFRONT 服务目录/合同为准。

L3 Sales 单独负责客户关系、咨询事实、获批准范围、报价、签约与交付承诺。VRAE 不得把报告生成、点击、扫码或内部审核自动升级为 E2/E3。

### 2.2 应用与技术架构

复用唯一 API/独立 Worker、现有 Evidence→Guard→原生工业 C1→C2 DeepReport→同一个签名 SSR Controlled Review→C3 内部 Brief。禁止新增第二报告/SSR/审批权威。

- Worker 的当前30秒租约只约束该 Worker 有效领取与提交；严禁提升租约、禁用提交前重放或把 L2 AI 长推理塞进已冻结租约内。可选 AI 阶段在已接受的确定性产物之后独立执行，使用自己的有界任务/预算/超时，不再写原 Worker 完成事实。
- 真实 L2 整机必须以同一**新创建** APP202 request/run/job/evidence 为准，复核 C1、C2、Review、Brief 一路共用的具体版本、哈希及现行受权主体，不能拼接 Detached/历史样例。
- C2 当前授权和 M1 当前签名任务都须同时持有与重验直到 Brief 真实 COMMIT；采用二者最短原有有效期。新专用 PG 库与 C2 SQLite 账本不是同一个原子事务；通过版本栅栏、CAS、提交前和读回时的权限/版本校验、幂等、可补偿中间态阻断撤权竞态。
- 安全访问仅有证据/已授权范围；网络不可达、robots/WAF/403、动态未解析均为受限/UNKNOWN，非网站业务故障。

### 2.3 数据架构

权威与引用：VRAE 管源证据/规则/行业分析、L2 报告/审核；VF 管真实客户、线索、业务确认和报价；Vey2GE 可经合同接收经核实增长事件；L2M 仅在授权交付后接受 RebuildBrief/许可素材副本。跨系统不共享数据库。

必须记录版本链：tenant、request/run/job/event、source/pack、rule/IndustryPack/diagnosis、model/prompt（若使用）、report_ref/version/content_hash/display_hash、review receipt/当前授权期限、brief_ref/hash、首次created_at、来源模式及原始证据时间。不同 SHA 代表不同对象，不得使用 PDF/HTML SHA 冒充完整业务报告 SHA。

数据状态至少区分：OBSERVED / UNKNOWN / ACCESS_BLOCKED / NOT_APPLICABLE、AI_NOT_RUN / AI_INVALID / AI_CANDIDATE / AI_REVIEW_REQUIRED、REPORT_DRAFT / CONTROLLED_REVIEW / FORMALLY_VERIFIED（后者未启用）、INTERNAL_BRIEF / HANDOFF_AUTHORIZED（后者未启用）。历史原始证据与修订事件追加保留，不隐式覆盖。

模型费用、浏览器费用、CPU/存储、人工审核、触达分别核算；UNKNOWN ≠ 0；E3=0 时合格商机成本分母不可计算。隐私、版权、授权、删除与安全保留政策须在真实试点前确认。

### 2.4 AI 增强架构（V1.1 RA-3 的 L2 明确化）

现存 ModelGateway、AIInterpretation、Guard、UsageRecord 是唯一扩展入口，不创建未经审核的第二模型编排器。阶段能力：
- A0：确定性事实与规则报告；没有模型则明确 NO_MODEL/NOT_RUN，仍可给人工审核。
- A1：结构化事实投影与最小脱敏；包含 Source/Observation/Finding 引用、覆盖、反证、时间、量纲与待确认项；固定 prompt_version、model_version 和预算。
- A2：模型仅生成有界的采购商假设、易理解性候选、资料补齐问题、Rebuild 行动提案；绝不自行认证事实、工况工程适配、真实资质、成交/SEO结果。
- A3：Schema + 独立引用验证 + 语义人工审核：对客观断言以原证据逐条支持/拒绝；开放式 paraphrase/经营假设始终 REVIEW_REQUIRED，不能凭 ID 或模型置信度当作已验证事实。
- A4：逐项受控审阅、追加版本、报告/蓝图/Brief 与事实分离；AI 失败、预算不足或未知调用费直接降级到 A0，不形成假成功。
- A5：实际 Provider、供应商区域、条款、数据外传、真实费用限额必须另行授权；初始仅离线/模拟，不启用付费生产。

AI 是否增加客户价值由同源「无模型/模型辅助」双轨数据集、独立 Gold 和真实业务可用性衡量，不能以模型是否输出或文案更长代替质量提升。

## 3. 方法论、行业与质量

通用 V1.1 规则目录16项仍为权威，当前 main 通用执行器已启用 DISC-01、DISC-02、CTA-02、INFO-01、SEO-01、TRUST-01 六项；其余十项不得因生成 UNKNOWN 或存在 JSON 规则定义便记为已实现。独立工业包 IND-SELECTION/SPEC/DUTY/FIT/PROOF/RFQ 六项不是对十项的替代。

每条待启用规则需描述适用性、证据需求、正反例、UNKNOWN/NOT_APPLICABLE/ACCESS_BLOCKED、严重误报风险、对应行业包及原生重放。L2 同一报告可展示五维已评估、未覆盖、冲突、范围和未知，不汇总为无依据的总分。

行业扩展采用 IndustryPack 版本化配置、字段/单位/术语映射和适用性，不为每个行业硬编码新引擎。P40/V25 为第一灯塔，静态标签表之外的 PDF/曲线/图片、SPA、CMS、多语种、多型号关系必须明确能力状态；未支持记 UNKNOWN。

人工 Gold 是独立人员对原始证据的真实裁决，不是 Codex 夹具一致性或模拟签名。现有26项候选仍为 GOLD_LABEL_PENDING；验收要报告 TP/FP/FN/TN、真实分母、precision、recall、abstention、coverage、按站型/行业分层及严重虚构。原目标有 Gold 的 precision ≥90%，严重事实虚构0；分母不足只能 QUALITY_NOT_EVALUABLE。

## 4. 阶段门禁的严格区别

- **S0 内部工业 L2 Beta**：真实 P40 APP202→Worker 30秒内合法COMMIT→同源C1/C2→同一SSR Controlled 审核→Brief PG COMMIT→真实浏览器及必要重启回读；禁止对外与真人正式审批。
- **S1 完整设计与验收规范**：本 V1.1 补强及对应矩阵正式受控、无权限边界冲突；不改代码事实。
- **S2 规则/行业/Gold**：五维、16条候选规则成熟度、覆盖及准确性具可审依据，未达能力说明清楚。
- **S3 AI 增强 L2**：独立模型运行、语义证据约束、真实预算、无模型/有模型效果和负例验收；仅经授权可开通模型。
- **S4 商业与客户验证**：正式身份、授权资料、有效 VF 咨询与报价流程、客户反馈和完全成本；E2/E3 由销售权威认定。

S0 完成不等于 S2/S3/S4 完成；S2/S3 不应倒灌成为 S0 在合成工业样本中的阻断。RA-5/RA-6 的实网、正式人审、外发及生产运营审批独立存在。
