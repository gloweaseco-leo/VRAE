# ADR-0002｜独立数据所有权与版本化接口

- 状态：ACCEPTED IN PRINCIPLE（目标架构），2026-11-10
- 实施：尚未开发 API/DB；本文件是边界契约

## 背景
VRAE 处理的是从外部网页获取的证据、运行结果和诊断报告；VEYFRONT 处理用户联系/报价；Vey2GE 处理增长经营与商机；L2M 处理网站建站交付。共享表会扩大越权和数据迁移风险。

## 决策
1. VRAE 有独立 PostgreSQL、私有证据存储与队列；不共用 Vey2GE 的数据库、schema 或管理员凭据。
2. 原始网页快照与已审核报告属于 VRAE；VEYFRONT 私有线索属于 VEYFRONT；Vey2GE 不因看到 audit ID 就拥有 E3 商机认定权。
3. 跨系统采用 Audit API V1、Growth Event V1 和 RebuildBrief V1 三份独立版本化合同。
4. 对外分享和交付输入只复制最小、获授权的数据；详细 Evidence 默认仅内部读。
5. 通过各系统的外部 ID 和经审核的关联记录交接，而不是以域名或企业名称自动合并法人。
6. 同一事实保持出处、权限引用、事件版本和幂等键；双方连接故障不得影响 VRAE 的诊断核心。

## 权衡
独立存储增加基础运维与 API 成本，但能单独实施 RLS、保留策略、备份、事故隔离与未来商业化。合同测试和事件 Outbox 是对抗分布式一致性复杂度的必要措施；首期只实现实际使用的连接，不为未来第三方系统提前建设总线。

## 不变量
未授权不分享、未批准不出报告、未保存成功不标 E2、未经人审不标 E3、公开可访问不等于允许商业复制；没有实际使用的生产接口不得宣称已集成。
