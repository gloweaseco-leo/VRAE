# VRAE 产品纲领与商业定位 V1.1

> 状态：ARCHITECTURE APPROVED IN PRINCIPLE / 文档基线。2026-11-10。
> 注意：本仓库目前只开展文档治理；本文件不代表功能开发、数据库创建、上线或真实商业结果。

## 1. 一句话定位

**VRAE（VEYFRONT Rebuild Audit Engine）** 是独立的、证据驱动的 B2B 企业网站采购商体验诊断引擎。它将经合法、受控观察的旧网站信息，转成可复核的诊断发现、可审核的改进建议及可授权交接的商业材料。

首个商业使用者是 VEYFRONT；VRAE 本身既不是 VEYFRONT 官网，也不是 L2M 自动建站器，不是 Vey2GE 多租户增长经营平台，更不是通用网站漏洞扫描器。

## 2. 为什么需要

中国出海制造企业的网站常常难以高效呈现产品、规格、工厂事实、信任证据和采购商询盘入口。VEYFRONT 当前缺少的是：如何以可信的、可解释的诊断结果启动商务对话，而不是纯展示建站页面、依赖流量等待转化。

VRAE 的核心价值不是给网站一个神秘总分，而是帮助企业回答：
- 海外采购商能否找到需要的产品？
- 是否能理解关键技术与应用信息？
- 能否核实企业主体和实际业务事实？
- 能否从具体产品走向有效的咨询路径？
- 网站是否具备被搜索发现的基础条件？

## 3. 增长闭环

精准企业发现 / 专业信任内容 / 伙伴推荐 / SEO-GEO
→ VEYFRONT 诊断入口或内部筛选
→ VRAE 安全采集与证据化评估
→ 人工审核的一页 L1 诊断
→ 客户主动沟通和需求确认
→ VEYFRONT Rebuild 方案与合同
→ 独立的 L2M 或人工受控交付
→ 经授权的交付案例、内容与推荐。

**北极星**：经责任人确认的 E3 合格商机，以及包含人工、模型和运行费用的获客成本。诊断次数、邮件发送、浏览量、扫码、GSC 曝光都不能自动升级为 E2/E3。

## 4. 客户与行业

- 第一目标客户：具有真实出口业务且已有英文网站的中国 B2B 制造/工业企业。
- 首批候选行业：机械设备及工业零部件，优先广东地区便于实地销售验证。
- 与 VEYFRONT 可交付范围一致：常规范围的 Rebuild 可参考当前 VEYFRONT 公示价格；复杂平台/数据库、多站点及大规模迁移需要单独评审。
- ICP 是优先实验假设，不能声称已经获得销量、需求规模或成交证明。

## 5. 分层产品

| 等级 | 受众 | 交付与规则 | 外发边界 |
| --- | --- | --- | --- |
| L0 Scout | VEYFRONT 内部销售 | 公开证据、企业适配、候选问题；规则优先、无模型 | 只内部使用，不直接对外发布 |
| L1 Initial Audit | 获准接收报告的潜在客户 | 1 页、至多 3 个真实可信问题、证据和建议，人工批准 | 人工审查与定向授权分享 |
| L2 Deep Audit | 已确认兴趣且有网站属主授权的客户 | 深度采购商旅程、产品结构、改造蓝图 | 独立授权与商务范围确认 |
| L3 Sales | 已进入采购讨论 | VEYFRONT 正式方案、报价、验收和交付责任 | 人工批准，不由 VRAE 自动报价 |

L0 和 L1 必须严格分离。免费诊断有审核、运行与获客成本，不能为追求任务数无限运行。

## 6. 明确非目标

- 自动重建/发布任意第三方网站、克隆其素材或修改其生产系统；
- 自动陌生客户外发、加微信、广告消费或销售签约；
- 对任意 URL 无限制爬取、绕过登录/robots/访问控制；
- 未经真实权威数据证明就宣称转化率提升、丢失销售额或 Google 实际排名；
- 一次性建设通用 CRM、多 Agent 平台、内容农场或 SaaS 市场。

## 7. 首版商业成功条件

工程验收与商业验证必须分开：
- 技术方面：来源安全、证据可追溯、规则可重放、未能核实则显示未知、客户可见报告全经审核。
- 商务方面：实际目标企业愿意阅读报告、开展双向业务讨论，并能产生有证据的正式报价/合格商机。
- 可扩展方面：新增行业主要采用行业包/规则扩展，不得为不同客户硬编码一套引擎。

## 8. 角色与决策权

VEYFRONT 负责客户关系、同意、报价、交付承诺；VRAE 负责诊断过程和证据；Vey2GE 未来负责增长经营；L2M 负责已授权的重建交付。VRAE 不拥有联系人主档和销售成交事实，不能自行将报告标成商机。
