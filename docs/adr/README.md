# VRAE Architecture Decision Records

ADR 专门保存影响仓库归属、应用边界、数据所有权和安全策略的架构决策，不替代当前设计文档。

- [ADR-0001｜独立 VRAE 仓库与模块化单体](ADR-0001-independent-engine.md)
- [ADR-0002｜数据所有权与版本化接口](ADR-0002-data-ownership-and-contracts.md)

状态词：PROPOSED（待评审）、ACCEPTED（已认可）、SUPERSEDED（由新 ADR 取代）、REJECTED（拒绝）。

增加 ADR 时至少写背景、候选方案、选择及原因、影响、可复审条件和版本日期。不能靠直接改旧文档来掩盖架构变更。
