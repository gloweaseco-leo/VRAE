# L2 第二步：五维复核与买家静态旅程

PR #183、#184 已按 Owner 指示合并。本增量从合并主干继续，交付现有证据的五维统一读取投影，不部署、不改 VF 仓库、不修改历史工件或共享模型账本。

依据 [产品章程](../../../00-product/PRODUCT_CHARTER_V1.1.md)、[诊断方法论](../../../02-domain/AUDIT_METHODOLOGY_AND_RULES_V1.1.md)、[业务旅程](../../../02-domain/PRODUCT_AND_OPERATOR_JOURNEYS_V1.1.md)、[系统架构](../../../01-architecture/SYSTEM_AND_APPLICATION_V1.1.md)及[数据架构](../../../01-architecture/DATA_ARCHITECTURE_V1.1.md)。L2 是分析深度；保持原有授权和正式报告审核边界，客户仍只输入网址并接受一次授权声明。

## 本次行为

对已有 `l2-industrial-1.0.6` 工件，现有 API 完成当前权限检查和原工件重放后，增加可选 `buyer_review`，并在 `customer_presentation` 中提供同一投影。它绑定原工件 SHA、EvidencePack 和原生规则执行引用，拥有独立 `vrae.buyer-review.v1` 契约及内容引用，不写入原诊断哈希，不改变原诊断版本。不向旧任务回填新结果。

复用已有 `evaluate_s2`、固定的 `s2-projection-1.2.0`、行业配置、六个 S2 静态/工业候选检查，将应用入口、技术资料、证明材料上下文、声明标识下一致性、静态产品文字/链接、保存的页面响应分配至对应买家维度。询盘维度保留现有 CTA 规则与路径，本步不新增 S2 询盘判断。

原生规则结果始终独立保留。S2 候选的 `PASS` 仅表示其有限检查有证据可复核，`isNativeFact=false`、`humanReviewRequired=true`；不能提升为原生 PASS、事实准入或审核批准。未知、访问受限及配置不适用各自保留。S2 投影校验失败时显示 `CANDIDATES_UNAVAILABLE`，仍交付已有原生事实、采购资料卡和静态路径。AI 的待处理/失败状态也不清空这些内容。

复用原 `buyer_journey` 中首页→分类→产品→联系的路径和原始观察指针。只连接同一已采集快照，断开或未知步骤停止；最多交付 16 条路径，显式保留截断数量。路径中的产品端点与采购卡同一来源快照时，参考消费端给出 `productScopeRefs`；这只建立页面区域关联，不证明 SKU 身份、规格适配或型号被传入表单。

S2 每条规则最多交付 16 个候选，保留总量和截断标志。仅导出原证据身份、摘要及来源位置，不导出 S2 原始页面片段或联系方式；HTTP 错误记录不能伪装为成功访问页面。资料链接和证明材料未形成有证据的连续路径时，`technicalMaterialRoute`、`proofRoute` 保留 UNKNOWN。完整静态路径也不代表表单可用、消息送达或 E2/E3。

这是现有工件的读取投影，不增加 Worker 的生产计算，不延长租约、扩大页面范围、调用模型或改变模型提示。读取时重新计算，不缓存当前权限。

## VF 消费

同步 `consumer/buyer-review.mjs`、`reference.mjs`、`report-view.mjs`、`vf-preview-adapter.mjs` 和类型声明，保留上一步的 `procurement.mjs`。

- 每个 `buyerTasks` / `reportView.tasks` 分组同时包含原生 `observations`、采购卡（理解产品维度）、`reviewCandidates` / `reviewCoverage` 和现有 AI `insights`。
- 顶层和 `reportView.buyerReview` 提供路径、候选层状态、覆盖数量及未证实边界。页面需明确区分原生事实、待复核候选、AI 假设，不能将候选计入确定缺陷或评分。
- 参考适配器核对工件引用、投影副本、实际访问/失败记录、证据绑定、路径观察指针、连续快照和覆盖数量。引用比较按完整 JSON 内容进行，不依赖对象键的序列化顺序。
- 新扩展可选，旧服务/旧任务读取仍兼容；旧 VF 未同步时不会自动展示这些字段。VF 页面实现与应用类型检查仍由 VF 团队负责。

## 验证

`frozen-review.json` 为历史真实六页采集证据的只读反事实重放，非新授权任务、非正式报告：五维共 14 个候选（6 个有限证据候选、8 个 UNKNOWN），4 条路径，其中 2 条静态完整路径；原采购卡保留。人工审核均未批准，AI 结果为空时参考消费仍输出全部这些内容。

本机已观察样本新增读取投影约 0.27–0.53 秒，非线上 SLA。27 份历史结果按原版本重放，原数据、回执和共享模型账本未变。没有访问客户网站，没有新增真实模型调用。隔离 PG 使用协议替身，不能当成真实 Qwen 回执。

`validation.json` 记录最终回归及隔离 PG 检查。源绑定反例覆盖工件错配、未访问页面、证据丢失、错误观察指针、虚构完整路径、不连续路径、伪造提交/型号传递，以及合法键顺序变化。VF 仓库和生产配置未改。
