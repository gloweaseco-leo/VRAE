# VRAE 客户与运营应用旅程 V1.1

> 状态：目标应用产品规格 / 未实现页面。2026-11-10。

## 1. 两种获客进入同一个诊断核心

### A｜精准企业开发（内部发起）
目标企业来源及合法性复核 → 候选企业登记 → L0 公开只读核查 → 内部审核是否值得开发 → 形成客户沟通草稿 → 人工审批首次商务接触 → 客户真实回应且同意进一步讨论 → L1/L2 → VEYFRONT 咨询/报价。

没有回应时不发送详细的、可能贬损客户的完整公开诊断；不要将“网站有缺口”误判为“客户有预算”。目标企业来源、官网、行业、初筛和联系状态分开存储。

### B｜客户自愿申请（官网/伙伴/内容/搜索）
客户从 VEYFRONT Rebuild 页看到诊断方法、范围和隐私信息 → 输入网站 → 接受限定检查 → 申请被 VRAE 持久受理 → 查看安全的最小进度 → 人工审阅后获得有限报告 → 自愿通过企业微信/表单进入进一步沟通。

匿名用户不可遍历报告 ID 或无限次触发抓取；是否先允许匿名免费初查是单独的商业决策，不作为第一阶段默认开放功能。

## 2. 客户前台由 VEYFRONT 拥有

客户只看到 VEYFRONT 品牌，VRAE 不强迫用户创建第二个账号，也不要求了解后台服务名称。

| 页面/状态 | 需要表达 | 禁止承诺 |
| --- | --- | --- |
| Rebuild 诊断介绍 | 目标买家、诊断方法、可能得到什么、隐私和授权范围 | “保证提升询盘/SEO 关键词排名” |
| 输入站点 | URL、用途、是否属主、许可范围、适当告知、限额 | “输入即自动修改网站” |
| 已受理 | 任务编号、持久受理状态 | 立即宣称分析完成 |
| 进行中 | 正在采集/规则检查/待人工复核的简明状态 | 展示模型原始思考/凭据 |
| 受限/失败 | 来源拒绝、证据不足、任务失败的友好说明 | 将抓取失败包装成质量缺陷 |
| 已审核报告 | 1–3 个有证据的问题、建议、限制、当前 Rebuild 服务边界 | 未证实的损失额、虚构证书/项目 |
| 商务动作 | 联系企业微信、提交正式 VF 咨询、确认方案 | 将扫码或点击视为真实商机 |

## 3. 内部审核工作台由 VRAE 拥有

第一版不需要复杂独立 SPA：可采用服务端模板 + 轻量交互，在 VRAE 受保护域名运行。核心工作区：
- 任务池：待办/阻断/运行/补证据/待审核/已批准/已分享与费用；
- 证据：并排查看页面 URL、时间、截图及规则的实际定位；
- 审核：对每个 Observation、Hypothesis、Recommendation 拒绝、改写、批准；原始证据不可编辑；
- 运营交接：仅将已批准版本与不透明 VF 引用相关联，人工确认对方是否真正愿意沟通。

权限：
- Operator 可提交和观察已分配任务，但不能无审阅生成已分享报告；
- Reviewer 可审批已授权的具体版本，不能跨租户；
- Owner 可发放/撤销分享授权和管理 SourcePolicy；
- 外部客户只访问自身被授权的已批准报告。

## 4. 一份 L1 报告的客户可见格式

1. 报告标题、企业公开网站、日期、覆盖页范围及说明；
2. “海外买家想完成什么任务”的最小采购旅程；
3. 最多三个重要发现：**证据事实 → 可能影响（假设）→ 建议动作 → 验证方法**；
4. 哪些问题属于标准 Rebuild 的候选范围，哪些需要客户业务资料和定制报价；
5. VEYFRONT 提供的真实下一步：15 分钟讨论、企业微信沟通、Rebuild 服务说明；
6. 版权、使用范围及“未检查部分不代表无问题”的明确标识。

不得生成缺少真实数据支撑的全站评级、营收损失、销售线索数量或搜索排名结论。

## 5. L1 → L2 → L3 商业转换

- 客户点击 CTA 是 E1 意向行为，不是已确认咨询；
- VF 表单确实落入私有存储并产生唯一收据才计入 E2；
- 企业微信需人工确认实际联系，单纯扫码不计 E2；
- E3 需明确企业、需求、业务适配、购买路径和下一步，并由负责人确认；
- 只有签署/收款/正式进展证据才能宣告更高业务结果；
- L2 属主授权独立于 L1 的公开页观察许可，不能自动升级权限。

## 6. 运营体验验收

- 客户可在手机及微信内置浏览器完成“了解→申请→得到真实状态→经授权查看”；
- 当 Worker 无法获取网页时客户看见真实受限状态，并可选择人工联系；
- 内部审核可以精确看到每条结论的来源，能拒绝并留痕；
- VF 线索保存、投诉/删除请求和分享撤销有明确人工负责人；
- 报告未被审阅、过期或撤权时，所有外部访问都必须拒绝；
- 不因 Vey2GE 或 L2M 当前未就绪而失去诊断能力。
