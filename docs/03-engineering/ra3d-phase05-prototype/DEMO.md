# 中文演示脚本 · 约 2–3 分钟的讲解安排

这只是讲解节奏，不是测得的真人审核耗时。用本地 Chromium 打开 [index.html](index.html)；无需网络。全程指明“离线交互模拟 · 非真实审核/审批/分享”。

**0:00–0:45 / 从事实回到原文。**

“我们只审一个有依据的问题，不给网站打神秘总分。合成产品页指向 `/contact` 的链接，在固定捕获中返回 404。”点击“查看原始证据”，指给观众看完整 URL、href、时间、状态、引用和 UTF-8 `[124, 163)`。展开完整原文，说明恶意标签/指令只是惰性文字，没有执行。点击“返回原问题”，观察焦点恢复。

“字面事实有边界。采购商可能绕行仍是假设，不能说已丢单，更不能推断收入、Google 排名、资质或工厂真实性。”逐项核对事实、保留假设、候选行动、验证授权、范围、全文和内部边界。点击“检查正向模拟前提”，阅读二次确认，先返回，再重新确认。指出结果是“模拟满足审核条件，未形成真实 APPROVE”；顶部仍是 NOT APPROVED，没有分享入口。

**0:45–1:15 / 意见要具体，原文不能直接覆盖。**

重置当前场景，在“可能影响”填写“请保留可能/假设表达，不能写成实际丢单”。点击模拟退回并确认，展示意见原样保留、本轮关闭。再重置，填“不适合本轮商务沟通，需补充上下文”，演示拒绝。本页不能直接改证据、改 Guard 或把拒绝翻成通过；继续需新版本，任意改写输入方案仍待未来 Owner 审查。

**1:15–1:45 / 零问题不会凑一份报告。**

切到场景 02，核对独立 200 捕获。指出“200 不等于表单有效或邮件送达”，403/WAF 是未能检查，UNKNOWN 仍未知。打开原文，勾选三个范围/全文/内部边界项，仅确认内部检查范围。画面里没有批准动作；native ReportVersion 始终 null。

**1:45–2:15 / 一个页脚变化也会失效。**

切场景 03，打开原文并完成七项核对，做一次正向模拟。选“页脚”，点击“模拟所选变化”。展示旧结果的“当前失效”，旧核对被清空；打开新模拟版本，仍需全审。再重置选择“来源对象”或“引用”，观察没有自行重绑定入口，必须重置固定夹具。说明生产会需要服务端独立重放，浏览器对象比较没有权威。

**2:15–2:45 / 不是给角色换个名字就有权限。**

切场景 04，键盘选择跨租户、未分配、Guard REJECTED。拒绝视图没有目标 id、来源 quote 或正向按钮。说明这些是固定合成拒绝场景，不是登录/角色切换，静态文件不是安全边界。最后刷新页面，之前的模拟结果消失。

收尾提示：后续 Owner 分享为 NOT IMPLEMENTED；真实认证、不可变对象、全内容绑定、持久事务与接收人访问都需要独立实施和验收。本演示没有产生实际人工批准或客户报告。
