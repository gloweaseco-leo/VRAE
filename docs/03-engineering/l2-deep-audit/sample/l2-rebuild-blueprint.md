## 1. 先恢复可用的产品询价路径

阶段：先修复已证实阻碍

改善页面／信息：MP25 产品模板 + Contact/RFQ

### 为什么值得讨论

- MP25 的专用询价入口返回 404（OBSERVATION）

保留的 MP25 产品页“Request MP25 quotation”指向 /contact-old；该目标在本次离线记录中返回 404。

可能影响（假设）：可能使已选中 MP25 的采购员在准备询价时中断或额外寻找联系方法；实际点击率、送达和损失均未测。

- 通用询价页是否保留产品上下文尚待验证（HYPOTHESIS）

当前 /rfq 表单快照只显示 name、email、message 三个字段；静态结构中未显示型号字段。

可能影响（假设）：若后端未补齐上下文，销售可能需要再次询问型号、工况与需求数量；这是条件性风险。

### 建议怎么改

把失效专用入口替换为业务确认的有效路径；询价区同时显示型号与来源页，并说明需提供的工况。先复用现有收件流程，不擅自更换 CRM。 补充：收件核验只在已获准的测试收件箱中进行，并记录责任人与结果。

### 需要企业补充或确认

- 有效收件渠道与业务责任人
- 型号/来源上下文的现有处理方式
- 获准测试收件箱及提交测试许可

### 服务范围

标准 Rebuild 候选（按合同确认）

依据已验收 V1.1 纲领的常规网站 Rebuild 范围作候选分类；最终页面数、模板、内容量及合同须由 VEYFRONT 确认，不是报价承诺。

责任角色：客户销售负责人 + VEYFRONT 网站实施

依赖：业务确认入口；投递验证依赖 u-delivery

### 如何复验

- 从产品页进入获准询价页，不再返回404
- 型号/来源在获准的载荷及接收记录中一致
- 未获提交许可时只验收导航，投递结论保持UNKNOWN

## 2. 建立可复用的工业参数与技术资料模板

阶段：修复技术资料与内容结构

改善页面／信息：产品详情 + 技术下载区

### 为什么值得讨论

- 已保留参数表的单位与材质等级不足以直接比较（OBSERVATION）

MP25 参数表写 Capacity 5-100、Head 20-60、Material Stainless steel；在该表内未标注单位、材质等级和对应运行条件。

可能影响（假设）：海外采购员可能无法与统一单位的采购规格逐项比对，需要先向企业确认数值含义与材质。

- 性能曲线下载实际返回 HTML 占位页（OBSERVATION）

产品页将 /files/mp25-curve.pdf 标为 Performance curve；该记录为 HTTP 200、text/html，正文是 Document coming soon。

可能影响（假设）：采购工程师可能无法从此入口取得用于核对工作点的曲线，技术比较可能需要往返索取资料。

### 建议怎么改

结构化展示流量/扬程单位、转速、材质、介质/温度和接口；技术下载按型号与版本管理，资料未齐时提供真实的索取入口。不能由网页文字生成工程参数。

### 需要企业补充或确认

- 工程确认的代表型号参数及单位
- 有权使用且版本明确的曲线/规格PDF
- 型号与文档关联表及维护责任人

### 服务范围

标准 Rebuild 候选（按合同确认）

依据已验收 V1.1 纲领的常规网站 Rebuild 范围作候选分类；最终页面数、模板、内容量及合同须由 VEYFRONT 确认，不是报价承诺。

责任角色：客户工程负责人 + 内容编辑

依赖：u-engineering 资料确认；先从一个模板与两款产品试点

### 如何复验

- 代表型号网页与工程确认规格表逐字段一致
- 曲线入口下载正确文件并明确型号/版本/单位
- 未知字段不补造，明确索取资料方式

## 4. 把可信资料变成可核对的说明

阶段：资料核对后发布

改善页面／信息：About + Proof/Quality + Contact

### 为什么值得讨论

- 认证声明尚不足以完成主体核对（OBSERVATION）

- 可核对的企业名称与关系说明
- 资料权利与公开范围
- 证书主体/范围/有效期及更新责任人

- 现有URL清单与发布环境说明
- 优先保留页面与历史入口
