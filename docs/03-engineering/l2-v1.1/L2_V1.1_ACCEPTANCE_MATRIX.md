## 1. 状态、质量与验收口径

PASS = 精确同源 SHA 的代码、原生测试、必要真实 PG/浏览器、负例、签名/哈希和 Owner 独立回读完整且达到目标；
PARTIAL = 已有可验证部分，但还有缺项；
BLOCKED = 前置技术/权限或尚不存在的真实E2E阻断；
UNKNOWN = 当前缺乏可靠证据；
NOT_IMPLEMENTED = 缺对应运行能力；
NOT_EVALUABLE = 已有评估器但无法基于有效人工 Gold 计算质量。

任务状态 DONE 不等于结果 COMMITTED；PG marker restart 不等于该任务报告/审核/Brief 同 refs 回读；CI 36/36 不等于真实 P40/Worker L2 E2E；Controlled ≠ Formal Person Review；报价/E2/E3 ≠ 内部 Brief。

- 所有门禁：无凭据/客户原文外泄、无跨租户越权、旧版本/撤权拒绝、原 Evidence 不可覆写、零未经授权外部动作。
- 质量：具体 rule/model/Gold/行业版本与站型分层；有真实 Gold 时 precision 目标 ≥90%，严重客观事实虚构 0。Gold 不足返回 NOT_EVALUABLE，而不是将夹具一致率充当质量成绩。
- 来源：每条客观结论可回放到同 run 的 URI、观察时间、原始字节/locator/hash 和规则/行业版本；UNKNOWN 不可补成缺陷；未经观察的投递、排名、流失额和认证真实性仍 UNKNOWN。
- 人工和商业：内部 Controlled 审阅不可以发放真实 external ShareGrant 或客户同意。L3 报价和 E2/E3 按 VEYFRONT 权威另行审核。
- 每行归档字段：ID、适用性、main SHA、PR/测试 SHA、source/IndustryPack/model/prompt版本、run_id/job_id/pack_ref、原生JUnit/日志/截图/PDF/PG回读哈希、负例、结果、责任人、Owner结论及时间。仅当前实际存在的值填写，未知留空/UNKNOWN。
