# P2：有限自适应补充调查

本增量基于 PR 187，沿用 V1.1 的五维、16 条规则与现有采集、Worker、PG、Qwen、Guard、报告通道。客户仍只提交网址并勾选一次授权。没有新增平台、浏览器自动化、表单提交或人工签发步骤；正式报告审核要求保持不变。

## 行为

在自动诊断、PUBLIC_SAME_ORIGIN 范围且保留原始证据的采集中启用。先满足原选择器中尚未覆盖的 Home、Catalog、Category、Product、Contact、About 候选；再将剩余页数优先用于已有正文明确指向的补查链接，而非普通链接。

| 目的 | 有限触发条件 | 允许的来源 |
| --- | --- | --- |
| TECHNICAL_MATERIAL | 产品正文解析成功，但未记录到可用的结构化字段 | 同产品页面 main/article 等主要区域中明确标注 Technical data、Datasheet、Specifications 等的 HTML 链接 |
| APPLICATION_CONTEXT | 产品正文解析成功，但未记录到可用的 Application、Usage 等明确字段 | 同产品主要区域的 Application guide 等明确链接 |
| PROOF_CONTEXT | 企业页面主要区域有明确指向尚未访问证明材料的链接 | About 页中 Certificate、Certification、Case study 等明确链接 |

这三项是源码证据选择提示，不是新增诊断规则，也不证明整个网站存在缺陷。只使用明确标签的有限匹配，未扩展到任意语言、任意站点结构或任意文档类型。隐藏、导航、页脚、表单、含 base 的页面及解析歧义不产生补查提示；解析失败不能当作缺少信息。PDF 等原本被采集器排除的类型仍不抓取。

每轮最多补查 2 页，每个目的最多一次；与原代表页面共用原有总页数上限（自动任务通常 6 页，不能突破已授权配置，L1 硬上限 8 页）、请求、字节、时间与频率预算。没有增加页数配置、续租、费用上限或模型调用次数。只有剩余时间能容纳当前单次请求上限与间隔时才选择补查；这不是增加一个独立调查时间窗口。触发前的本地解析和完整性验证也消耗原有计算时间。

补查地址必须同时出现在已通过当前策略检查的 inventory，并与来源保持同源 HTTPS，不含查询、片段或凭据。每次访问仍经过当前授权、SSRF/DNS/TLS、robots 和现有安全停止逻辑。不会重试已尝试网址，不会跨域，不从 AI 生成网址，也不会自动访问被拒绝的页面。补查页发现的新链接仅进入候选清单，不递归扩散抓取；若其他基础页面独立发现该地址，仍按原基础逻辑处理。

## 证据及 VF 消费

可选 `CaptureManifest.adaptive_investigation` 随原清单哈希保存。每条决策记录原来源页面、原始链接 UTF-8 字节范围/正文哈希、触发条件和目标尝试记录。重放检查来源先于目标、原文确有符合条件的链接、目标来自清单、不同目的且不重复；不回写历史清单。选中地址后再次检查权限与预算，通过并开始尝试后才记入决策，避免撤权留下不存在的页面引用。

既有 `fact_review.supplemental` 交付来源和目标 snapshot、原证据绑定及停止原因；AI 失败或仍在运行时也可消费。VF 参考适配器在 `buyerTasks[].supplementalInvestigations` 和 `reportView.tasks[].supplementalInvestigations` 分组输出：技术/应用补查进入 UNDERSTAND，证明材料进入 TRUST。

每条结果明确为 CAPTURED 或 NOT_CAPTURED；目标的 HTTP 状态/失败原因来自既有 pageScope。`product_applicability` 与 `gap_resolved` 保持 UNKNOWN，`native_fact_admission=NONE`。发现链接、取得正文均不等于解决采购问题，不认证材料真假，也不将补查材料自动关联到其他产品。采集内容进入现有规则与 Qwen 证据流程，能否形成结论仍由既有证据标准、版本和 Guard 决定。

VF 团队需同步参考模块 `supplemental-review.mjs`、相关适配器及类型声明后自行决定页面展示；本次没有修改 VF 仓库或部署配置。旧工件不补造补查过程；没有扩展字段时返回空列表。

## 验证与实际限制

正反测试覆盖基础覆盖优先、两页和原总预算、非递归、已有字段不触发、robots 拒绝不发起网络、选中后撤权保留旧证据、原文/引用篡改拒绝、服务投影和 VF 消费。另验证隔离 DNS/TCP/TLS 与 PG 链路。结果见同目录 JSON。

最新授权报告的留存证据只读重放时，5 个已访问页面没有命中本策略的安全补查链接。因此不能预言同站下一轮一定多抓页面或补齐未知结果；没有合适来源时保持原有结果。该重放未访问候选页面、未调用真实 Qwen、未修改历史工件或共享模型账本。新增补查行为通过合成来源与隔离真实网络栈验证，不能冒充新的客户网站线上验收。

本增量未合并、未部署，等待 Owner 独立验收。
