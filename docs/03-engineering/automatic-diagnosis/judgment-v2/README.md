# 判断 v2

`vrae.diagnosis-judgment.v2` 只出现在 `l2-industrial-1.0.8`。1.0.7 仍是 `vrae.diagnosis-judgment.v1`。

`confirmed_obstacles` 本轮为空，因为没有 L-C。L-B 的 `FAIL_WITH_EVIDENCE` 在 `evidenced_pending_review`，不计分。`unjudged` 只看启用规则。五个采购阶段是筛选、比较、技术确认、询价和技术访问。

1.0.8 的 `page_scope` 增加已选角色、已观察角色、未覆盖原因码，以及事先声明角色的覆盖分子和分母。未访问不是缺陷。技术访问事实写明：单次测量、含调度开销、不含 DNS、不是用户体验、不是评分；渲染性能和移动端本次未测。
