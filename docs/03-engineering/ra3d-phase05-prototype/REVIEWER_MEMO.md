# Reviewer 阅读备忘录

本原型让 VEYFRONT 的未来审核者练习三种判断：某句话是否仅描述捕获时的字面事实；影响解释是否仍是有界假设；修复/复核是否是候选行动且符合授权范围。它也让人实际操作退回、拒绝、零问题范围确认和版本变化后的停审。

使用时先点击原文，比较 quote、href、目标响应和字节定位，再回到问题。查阅过证据才允许核对事实；全部七项处理完成才出现正向模拟前提。原始 Guard 类型不因接受措辞而改变。单纯打开面板、勾选或出现模拟成功文字都不能证明理解、真实身份或完成审核。

容易混淆的地方：

- 404 是固定合成响应，不是对当前真实网站的检测；200 不是表单有效或送达证明。
- “可能影响”是解释假设，不能改称真实丢单、询盘减少或营收损失；网站文案也不是认证证据。
- “新模拟版本”只是固定夹具内存状态；没有生成生产 ReportVersion，也没有重新运行 RA-2/Guard。来源、引用、HTML 完整性改变不允许本页自行重绑定。
- 拒绝视图隐藏内容只是交互示意。所有合成夹具可从本地文件读取，不能用来声称跨租户隔离已通过生产验收。
- 页面字段中的 `sim-*` 是本轮夹具标签；不是现有证据链的权威 ref。浏览器 target 比较和文件 SHA 用于复核制品一致性，没有身份权威。
- “模拟范围已核对”始终只有内部意义，native=null；未来如果需要外发零问题摘要，须独立合同与 Owner GO。

建议复用：中文信息层级、事实/假设/行动/复核分层、来源点击与返回焦点、具体条目意见、二次确认、原文惰性展示、手机自适应和对版本失效的解释。可以把本轮断言作为未来 UI 验收素材，重新接到受信服务端后再测。

必须替换/舍弃：内存状态机、固定拒绝选项、客户端 fixture、`sim-*` refs 与 JSON 字符串相等判断不能进入权限判定；不能将前端 positive 结果接成生产 APPROVE。当前 DOM 重绘方式是原型便利实现，生产需审查稳定焦点、异步错误、并发和完整生命周期。

未解决的生产集成问题：真实身份/任务授权、独立来源 pins 与逐条 Guard 重放、原生/全文侧车运输、原始 HTML/资产完整字节绑定、服务端 CAS/幂等/可信时钟、不可变对象、事务/审计/outbox 和故障恢复均未实现。现有 RA3C 任意人工改写合同仍待 Owner 决定；本轮备注不回写报告。Owner 分享、consent、subject/token、撤销与逐次客户访问均未实现。

未测量的人类可用性：没有招募真实 Reviewer、可理解率/误判率、耗时、移动真机/微信浏览器、实际屏幕阅读器或认知负荷研究。浏览器键盘与可见焦点检查通过不代表完整 WCAG 审计。没有“90 秒人审”实测，也没有真实 E2/E3 或商业有效性结论。

已知原型限制：没有任务池/真实全报告 HTML 对照、服务端 diff 或会话过期恢复；原文面板手机端会滚到下方再返回；长 Guard 标签保留精确文字并折行。刷新会丢失备注和模拟结果，目的是避免离线存储，不能用于正式工作留痕。
