> 更新：2026-11-10。此表是当前建筑设计的评审状态，不是基础设施或交付验收报告。

## 1. 已认可的架构方向（不代表已部署）

| ID | 决策 | 依据 | 状态 |
| --- | --- | --- | --- |
| D-01 | 独立仓库 `gloweaseco-leo/VRAE` | 爬取安全/生命周期/复用边界 | ACCEPTED |
| D-02 | Python 模块化单体 + 受限 Worker | L2M Python 采集资产和浏览器工作负载 | ACCEPTED IN PRINCIPLE |
| D-03 | VEYFRONT 作为唯一首批商业前台和销售权威 | 现有官网、表单、企微与报价 | ACCEPTED |

| D-06 | VRAE 自有证据、规则、报告、审批和版本 | 可追溯、可纠错、可移植 | ACCEPTED |
| D-07 | 先 L0/L1、后 L2/L3 和公开自助 | 避免免费诊断滥用与成本失控 | ACCEPTED |

## 2. 尚未最终批准（不得自动实施）

| 决策点 | 候选方案 | 需核实的条件 | 放行时机 |
| --- | --- | --- | --- |
| DB 厂商 | VRAE 独立 Supabase/Postgres | 区域、费用、RLS、备份、合规 | RA-4 之前 |
| 队列 | PostgreSQL row leasing / pgmq | 任务恢复/重试/死信与容量 | RA-4 之前 |
| Worker 计算 | 受限托管容器 / 专有 VM | 网络隔离、资源费用、地区和运维能力 | RA-1/RA-4 |
| 模型与 API | 已授权的 Qwen 或其他适配 | 模型能力、真实价格、数据地区、schema | RA-3 |
| 免费 L1 配额 | 邀请制/白名单先行 | 防刷、安全、审核产能、客户体验 | RA-5/RA-6 |
| 报告分享 | 强身份查阅或限时 token | 客户安全、可撤销、监管与交付路径 | RA-4 |
| 证据存储期限 | 原始网页 30 天、报告 90 天为初步候选 | 法律主体、数据来源许可、客户协议 | 真实试点前 |
| 首批行业包 | 工业设备、工业零部件 | 真实样本、采购任务、规则覆盖 | RA-2 |

| 对外首次触达 | 人工审查的个性化业务沟通 | 合法依据、停止联系、对方真实回应 | RA-5 |
| 与 Vey2GE 的生产集成 | Growth Event V1 | 对方真实 Beta/低权权限和恢复验收 | Vey2GE 就绪后 |
