## 仍须区分的内容接入问题

上述 VF 源码仍只消费 evidence、coverage 和 claims；projectResult 没有消费 deterministic_diagnosis、analysis_outcome、capture_summary、page_scope 或 customer_presentation。
所以它即使成功读取，也会把6个已访问页面与候选范围合并成24条记录，缺少 AI 分析的其余维度仍显示 UNKNOWN，不能因此认定 VRAE 没有五维规则事实。
VF 后续应复用已交付的 consumer/reference.mjs 契约与测试，保留事实、区分未访问/证据不足/模型失败，并分开展示已访问页面和候选链接。该工作属于 VF 团队，不通过修改 VRAE 诊断事实来适配旧展示。

本轮没有改变顶层设计、五维体系、历史工件、原回执或共享模型账本。当前记录是故障调查及具体交接方案，不是已修复或真实页面验收通过的声明。
