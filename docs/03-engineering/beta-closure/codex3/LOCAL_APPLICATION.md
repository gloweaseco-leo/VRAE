# Local synthetic Beta entry

Owner scheduling: Issue96 comment6895932668 / Issue97 comment6895902508.
Accepted main inspected: a210d52ff10616113b9a5c2712fe7c0d8ac37be7.

Use the existing locked Python 3.11 or 3.13 environment, Docker Desktop, Node
and installed Chrome. Run from the repository root:

```powershell
python scripts/beta_internal.py app doctor
python scripts/beta_internal.py app start --run synthetic-beta-001 --minor 3.11 --component-preview
python scripts/beta_internal.py app status --run synthetic-beta-001
python scripts/beta_internal.py open --run synthetic-beta-001 --task 404
python scripts/beta_internal.py app stop --run synthetic-beta-001
python scripts/beta_internal.py app status --run synthetic-beta-001
```

Start runs the existing C3 PG16/API/signed Reviewer SSR supervisor in a hidden
background process. Status returns its loopback login URL only after the existing
startup has finished. The existing open command obtains a genuine signed test
session and opens the existing sealed Reviewer task in an interactive browser;
it does not grant authority over a new Worker-generated result. Stop requests the existing supervisor's cleanup; wait for
CLOSED, rather than treating STOP_REQUESTED as proof of cleanup. Each run name
is single-use. The supervisor's original 1800-second automatic cleanup remains.

The component preview runs the offline synthetic Collector, six rules and
versioned DISC report adapter, accepted original APP/Worker and signed SSR.
The SSR's existing sealed 404/200 tasks remain a separate test lane. They are
**not reports generated by those new Worker jobs**. The whole-app command
without --component-preview returns BLOCKED / exit2 until the Owner-merged
C1 generated-result commit/read port and C2 dynamic signed task/report/receipt/
export binding can be wired. No sibling Draft code is loaded. This preview
is not the requested L0-to-L1 whole-app PASS.

The launcher emits no signing token, cookie, database password, source HTML
or signer material. Private logs, per-run controls and evidence remain under
the existing .private directories; no public screenshot is generated here.
The original 375/200 CDP navigation RED remains preserved as c3-s2-disc-311-v1.
No authentication, SQL, RLS, Worker, HTTP/CDP thresholds or production path changed.

Stop is safe immediately after start: its signal lives in the reserved launch
directory, so it cannot pre-create the existing Run's exclusive directory.
Cancellation before startup reports CLOSED / CANCELLED_BEFORE_RESOURCES.
During startup it completes the current step and executes owned cleanup before
CLOSED. A startup/spawn exception without confirmed cleanup is reported as
FAILED_START_CLEANUP_UNCONFIRMED, never as ready or cleaned.

The internal supervise command only runs the existing local supervisor; it adds
no HTTP listener, role, business status or report authority. Control-only process
fault tests are separate from the actual PG/API/SSR lifecycle test. Neither
implies that the missing generated-result/Reviewer ports have been accepted.
