## 2. L2 的绝不漂移项与设计说明

- 北极星：支持 VEYFRONT 获得真实、经责任人确认的 E3 合格商机及其完全成本；VRAE 是证据与专业诊断事实权威，VF负责客户关系/报价/成交，Vey2GE将来负责可用增长事件，L2M负责获授权交付。
- 五维/通用16候选规则完整保留；当前6项通用规则启用、10项仍需S2；6项工业规则仅泵阀示例。Gold为0/26候选待签。保留 UNKNOWN/NOT_APPLICABLE/ACCESS_BLOCKED，不因缺证据变成FAIL。
- AI 是 V1.1 正式能力（RA-3），不是新的V1.2功能。S1冻结其**语义、信任边界、质量目标和接口路径**，S3才开发/验证实际真实Provider与推荐效果。无授权费用/数据地区/限额时调用数=0。
- 已验收 S0 的 PG/SQLite 边界只能称为两个权威加完成栅栏，不存在分布式单事务。正式 Reviewer、外部 ShareGrant、商机事件、L2M 交付必须逐一审批。
- 可以从合成/允许的公开只读资料做专业深诊，无实际私有资料访问权时相应部分 UNKNOWN。不得对网站属主要求“一律先授权”才能研究所有 L2能力；但也不得误将公开可读当可复制/外传/发布。
- 没有值的人工成本、真实AI费用、询盘成功送达/合同、搜索收录/排名、工程适配维持UNKNOWN，而不是随机填0或100%。
